# Security

## Reporting a problem

This is a public, documentation-only repository. If you find something wrong
in it, such as a broken link, a wrong checksum, or a claim that does not match
the record, please report it by opening an issue or by email:
noblebobo934@gmail.com.

## What this repo contains

There are no secrets here. No API keys, no tokens, no credentials, and no
unredacted device identifiers. The only data in this repo is facts.

The SHA-256 checksums and command outputs exist so that anyone can verify the
record against a stock build archive. Treat them as verification material
only. Always verify any image against your own copy of the stock archive
before flashing it.
